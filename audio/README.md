# Musik latar Jogja Siaga

Letakkan berkas MP3 (instrumental gamelan / nusantara, **lisensi bebas** untuk penggunaan proyek Anda) di folder ini dengan nama:

**`jogja-ambient.mp3`**

Contoh sumber bebas royalti: cari di [Pixabay Music — gamelan Indonesia](https://pixabay.com/music/search/gamelan%20indonesia/), unduh MP3, lalu rename menjadi `jogja-ambient.mp3`.

Tanpa berkas ini, tombol **Musik Jogja** tetap muncul tetapi pemutaran akan gagal diam-diam (cek konsol peramban jika perlu).
